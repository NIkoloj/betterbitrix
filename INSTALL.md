# BetterBitrix, версия 2.3.0

Tampermonkey-скрипт для `https://b24.entgld.com/`. Он работает через твою обычную сессию Bitrix: администратор, webhook, пароль и доступ разработчика к порталу не нужны.

## Как это работает

- **«Начать рабочий день»** запускает таймер на выбранной задаче.
- После запуска текущее время отображается прямо на основной кнопке.
- **«Пауза»** останавливает учёт перерыва; **«Продолжить»** возобновляет его.
- **«Завершить рабочий день»** останавливает таймер и записывает в задачу фактически накопленное время: часы, минуты и секунды в поддерживаемом Bitrix формате.
- Маленькая кнопка с часами и плюсом справа от основной сразу записывает **8 часов** в выбранную задачу — без запуска таймера.
- Таймер и разовая запись используют один дневной лок: после любого успешного варианта второй становится недоступен до следующего дня.
- Задача фиксируется в момент старта. Смена задачи по умолчанию во время работы не переносит уже запущенный таймер.
- Состояние хранится в браузере. Обновление или закрытие страницы не сбрасывает таймер: если он не был поставлен на паузу, прошедшее время продолжит учитываться.
- Положение панели и выбранная задача сохраняются. Панель можно перетащить за верхнюю строку и свернуть кнопкой `−`.
- Новый день начинается в 00:00 по часовому поясу конкретного пользователя. По умолчанию используется часовой пояс браузера; его можно изменить в настройках панели.
- Иконка календаря показывает сегодняшние события, в описании которых найдена ссылка Zoom или Teams. В меню видны название и время; нажатие открывает созвон.
- Иконка видеокамеры открывает постоянную ссылку на дейлик, которую пользователь один раз вставляет в настройках.

## Установка

1. Установи **Tampermonkey** из официального магазина расширений браузера.
2. В Chrome или Edge открой настройки расширения Tampermonkey и включи **Allow User Scripts / Разрешить пользовательские скрипты**. Разреши расширению работать на `b24.entgld.com`.
3. Открой страницу установки: `https://nikoloj.github.io/betterbitrix/`.
4. Нажми **«Установить BetterBitrix»** и подтверди установку в Tampermonkey.
5. Обнови страницу Bitrix.

Если BetterBitrix уже был вставлен вручную, открой установочную страницу и установи его поверх текущей версии. Это последнее ручное обновление: начиная с версии 2.3.0 новые версии проверяются и устанавливаются через штатный механизм обновлений Tampermonkey.

В Tampermonkey скрипт называется **BetterBitrix**, в заголовке установлен номер **2.3.0**. Обновления могут приходить не мгновенно: период проверки задаётся настройками Tampermonkey. Для принудительной проверки открой Tampermonkey и запусти проверку обновлений.

## Первоначальная настройка

Если версия 1 уже была успешно настроена, версия 2 автоматически перенесёт профиль записи, выбранную задачу и положение панели. Повторная ручная настройка не нужна.

Если профиль ещё не создан:

1. Нажми иконку шестерёнки в панели.
2. Выбери задачу. Если её нет в списке, открой карточку нужной задачи и нажми **«Текущая задача»**. Либо открой список назначенных тебе задач и нажми **«Обновить список»**.
3. Нажми **«Настроить Bitrix»**.
4. Через штатную форму учёта времени Bitrix сохрани в этой задаче **8 часов, 0 минут** с комментарием **`Работа над проектом`**.
5. Эта ручная запись уже является настоящей записью за текущий день. Таймер можно использовать со следующего рабочего дня.

Скрипт наблюдает только за этой явно включённой ручной настройкой и запоминает формат штатного запроса. Пароли, cookies и постоянные ключи он не сохраняет.

## Обычная работа

1. Проверь выбранную задачу под кнопками.
2. Нажми **«Начать рабочий день»**.
3. На перерыв нажми **«Пауза»**, после перерыва — **«Продолжить»**.
4. Нажми **«Завершить рабочий день»**. Накопленное время будет отправлено в задачу один раз.

Можно получить любое значение: например 7:43:12, 8:00:00 или 9:16:48. Если конкретная форма Bitrix принимает только минуты, скрипт округляет итог до ближайшей минуты.

Если таймер не нужен, нажми маленькую кнопку с часами и плюсом справа от основной — она сразу запишет 8 часов. После этого обе кнопки будут заблокированы до нового рабочего дня.

## Часовой пояс

- По умолчанию выбран режим **«Автоматически»** — используется системный часовой пояс браузера каждого сотрудника.
- При необходимости открой настройки и выбери нужную зону вручную.
- Дневной лок сбрасывается в 00:00 по выбранной зоне, а не одновременно для всех по Москве.
- Во время активного таймера, нерешённой записи или после успешной записи за текущий день часовой пояс менять нельзя.
- VPN сам по себе часовой пояс браузера обычно не меняет; автоматический режим ориентируется на настройки системы.

## Созвоны сегодня

1. Нажми иконку календаря в заголовке панели.
2. Скрипт запросит события личного календаря текущего пользователя за сегодняшний день через его действующую сессию Bitrix.
3. Для каждого события проверяются обычные поля описания `DESCRIPTION` и `~DESCRIPTION`.
4. Если в описании есть HTTPS-ссылка Zoom или Microsoft Teams, событие появится в меню с названием и временем.
5. Нажми на строку события — ссылка откроется в новой вкладке.

Отклонённые события не показываются. События без поддерживаемой ссылки в описании тоже не выводятся. Календарь загружается только после нажатия на иконку; токены, список событий и описания постоянно не сохраняются.

Текущий день определяется по часовому поясу, сохранённому в настройках календаря Bitrix, а не по VPN, часовому поясу браузера или настройке сброса рабочего дня. После ответа календаря скрипт дополнительно отбрасывает события других дат. Время созвона берётся напрямую из строк `DATE_FROM` и `DATE_TO`, а сортировка выполняется по показанному в них времени — без UTC-пересчёта.

Получение календаря использует локальный REST-клиент текущей установки Bitrix. Закрытый корпоративный портал нельзя было проверить напрямую. Если панель покажет ошибку загрузки календаря, пришли только текст ошибки — cookies, sessid и сетевые запросы присылать не нужно.

## Дейлик

1. Нажми иконку шестерёнки.
2. Вставь в поле **«Ссылка на дейлик»** HTTPS-ссылку Zoom или Teams.
3. Нажми Enter или кликни вне поля — ссылка сохранится локально.
4. Теперь иконка видеокамеры открывает дейлик одним нажатием.

Ссылка хранится отдельно для каждого пользователя Bitrix только в данных сайта этого браузера. Чтобы удалить её, очисти поле.

## Защита от повторов

- Один завершённый рабочий день записывается только один раз.
- Двойной клик, параллельные вкладки и повтор после перезагрузки не создают дубликат.
- Пока запрос выполняется, кнопки блокируются.
- При сетевом сбое, тайм-ауте, HTTP 500 или неоднозначном ответе автоматический повтор запрещается.
- В таком случае открой журнал времени задачи и только после проверки нажми **«Проверил: записано»** или **«Проверил: записи нет»** в настройках панели.
- Явный отказ Bitrix не помечается как успешная запись.
- Данные каждого пользователя Bitrix хранятся отдельно.

Защита действует внутри одного профиля браузера. Ручные записи, другой браузер, другой компьютер, инкогнито и очистка данных сайта скрипт контролировать не может.

## Если что-то не работает

- Панели нет: проверь, что Tampermonkey включён, пользовательские скрипты разрешены и расширение имеет доступ к `b24.entgld.com`, затем обнови страницу.
- Показывается старая версия: открой редактор скрипта и проверь строки `// @name         BetterBitrix` и `// @version      2.3.0`, затем запусти проверку обновлений Tampermonkey.
- Нет нужной задачи: открой её карточку и нажми **«Текущая задача»**, либо открой страницу списка задач и нажми **«Обновить список»**.
- После завершения неизвестен результат: не запускай повтор до проверки журнала времени в самой задаче.
- Если Bitrix сообщает о несовместимом формате, пришли текст или скрин сообщения панели. Не присылай cookies, sessid, токены или полный сетевой запрос.
