# BetterBitrix

Минималистичная панель для Bitrix24: таймер рабочего дня, быстрая запись восьми часов, список сегодняшних Zoom/Teams-созвонов и ссылка на дейлик.

Ссылки на созвоны распознаются также в HTML-гиперссылках и BBCode. В настройках можно включить показ всех сегодняшних событий календаря; строки без ссылки будут неактивны.

Версия **2.3.2** исправляет пропадающие повторяющиеся встречи и выход карточек созвонов за границы панели. Открытый календарь обновляется каждые пять минут и при смене дня.

Для Windows доступен [BetterBitrix Portable 0.3.2](https://github.com/NIkoloj/betterbitrix/releases/tag/v2.3.2): приложение для трея с включённым .NET 10.0.13. [Инструкция](windows/README.md) · [обновить мост Tampermonkey](https://nikoloj.github.io/betterbitrix/windows/companion/BetterBitrixPortable.user.js).

## Установка

1. Установите Tampermonkey.
2. Разрешите расширению выполнять пользовательские скрипты и работать на `b24.entgld.com`.
3. Откройте [страницу установки](https://nikoloj.github.io/betterbitrix/).
4. Нажмите **«Установить BetterBitrix»** и подтвердите установку.

Если старая версия была вставлена в Tampermonkey вручную, установите BetterBitrix по ссылке поверх неё. Начиная с версии 2.3.0 обновления доставляются автоматически.

Подробная настройка и описание защитных механизмов находятся в [INSTALL.md](INSTALL.md).

## Выпуск обновления

1. Изменить код в `BetterBitrix.user.js`.
2. Увеличить одинаковое значение `@version` в `BetterBitrix.user.js` и `BetterBitrix.meta.js`.
3. Обновить номер версии в документации.
4. Проверить скрипт локальными тестами.
5. Загрузить изменения в ветку `main`.

Tampermonkey проверяет лёгкий файл `BetterBitrix.meta.js` и при появлении новой версии скачивает полный `BetterBitrix.user.js`.
