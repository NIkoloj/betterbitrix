# BetterBitrix 2.3.2 / Windows Portable 0.3.2

- Повторяющиеся встречи фильтруются по дате конкретного повторения. Сохранённая UTC-метка первого события серии больше не скрывает следующие встречи. Удалённые и отклонённые события исключаются.
- Открытый веб-календарь обновляется каждые пять минут, при смене календарного дня и пользователя. Кэш повторного открытия ограничен пятью минутами.
- Длинные названия и строки без пробелов переносятся внутри карточек веб-панели и Windows. В Windows отключена горизонтальная прокрутка, элементы шапки размещены в ограниченной сетке.
- Windows-мост собирается из текущего общего кода, поэтому исправления календаря и таймера входят в обе версии. У моста добавлены адреса автоматического обновления Tampermonkey.
- В автономный EXE включены .NET, ASP.NET Core и Windows Desktop Runtime 10.0.13. Сборка проверена на официальном SDK 10.0.402.

## Обновление

1. Обновите BetterBitrix через Tampermonkey или [ссылку установки](https://nikoloj.github.io/betterbitrix/BetterBitrix.user.js).
2. Обновите [мост Portable](https://nikoloj.github.io/betterbitrix/windows/companion/BetterBitrixPortable.user.js), сохраняя существующий скрипт и его хранилище.
3. Закройте Windows-приложение через трей. Замените EXE и сопутствующие файлы из `BetterBitrixPortable-0.3.2-win-x64.zip`, сохранив папку `data`.
4. Перезапустите приложение и обновите вкладки Bitrix.

## Проверки

77 тестов JavaScript, включая три последовательных недельных повторения с исходной UTC-меткой, удалённые события, истечение кэша и смену дня. Проверены локальный транспорт, переподключение, сохранение таймера, защита от повторной записи времени и запуск автономного EXE. Календарь WPF отрисован на ширине 370 и 410 пикселей; проверено отсутствие выхода карточек и текста за границы. В браузере проверены совместная загрузка веб-панели и моста, длинные названия и отсутствие горизонтального переполнения.

В этой проверке нет доступа к рабочему профилю Tampermonkey и авторизованному календарю портала; корпоративные события и запись времени не изменялись. Регрессия повторов воспроизведена на тестовых ответах Bitrix с отдельными полями даты повторения и UTC-метки серии, описанными в [официальном API](https://apidocs.bitrix24.com/api-reference/calendar/calendar-event/calendar-event-get.html).
