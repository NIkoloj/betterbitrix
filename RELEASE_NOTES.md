# BetterBitrix 2.3.4 / Windows Portable 0.3.4

Исправлены пропуски ссылок на созвоны, которые находятся в поле «Место» события Bitrix или ведут через Outlook Safe Links. Ссылки `https://teams.microsoft.com/meet/…?p=…` сохраняют полный адрес и параметры подключения.

- Общий обработчик читает `DESCRIPTION`, `~DESCRIPTION`, `LOCATION` и `~LOCATION`. Ссылки в описании имеют приоритет; поле «Место» используется, если в описании нет поддерживаемой ссылки.
- Распознаются ссылки `*.safelinks.protection.outlook.com`, только если их единственный параметр `url` ведёт на разрешённый адрес Teams или Zoom. При открытии сохраняется исходная защищённая ссылка и проверка Microsoft; назначение используется для определения сервиса.
- Windows допускает эти же защищённые ссылки при открытии. Teams, Zoom и строки без ссылки проходят через один транспорт и сохраняются в календаре без потери параметров.
- На странице установки добавлена короткая инструкция: Tampermonkey, разрешения браузера, выбор задачи и первая настройка Bitrix. Отдельно объяснены настоящая запись 8 часов за сегодня, запуск Windows и установка моста.
- Сохранены исправления повторяющихся встреч, общий таймер и защита от повторной записи.

## Обновление

1. Обновите [BetterBitrix](https://nikoloj.github.io/betterbitrix/BetterBitrix.user.js) до **2.3.4** и существующий [мост](https://nikoloj.github.io/betterbitrix/windows/companion/BetterBitrixPortable.user.js) до **0.3.4**.
2. Закройте Windows-приложение через трей и замените файлы из `BetterBitrixPortable-0.3.4-win-x64.zip`, **сохранив папку `data`**.
3. Запустите приложение, обновите вкладки Bitrix и нажмите «Обновить» в списке созвонов.

Удалять скрипты, повторять первоначальную настройку и записывать дополнительные 8 часов при обновлении не требуется. При обновлении существующего моста сохраняется его связывание.

Архив для распространения содержит только EXE со встроенным .NET 10.0.13, мост Tampermonkey и README; личные данные не включены.

## Проверки

84 теста JavaScript, включая воспроизведение потери ссылок до исправления: Teams `/meet/` из описания, поля «Место» и приглашений Outlook, Zoom, события без ссылки, сохранение параметров, повторы встреч, общий таймер и транспорт.

Проверены URL-фильтр Windows, локальная передача и сохранение смешанного календаря, авторизация, переподключение, неопределённые записи, отрисовка WPF, состав ZIP и автономный запуск EXE. Контрольная сумма и встроенный мост сверены с текущей сборкой.

Доступа к авторизованному порталу пользователя нет. Исправлены и проверены перечисленные варианты данных; конкретный ответ его календаря не исследовался.

Форматы полей: [Bitrix REST](https://apidocs.bitrix24.com/api-reference/calendar/calendar-event/calendar-event-get.html), [ссылка конференции в поле Location](https://helpdesk.bitrix24.com/open/25575444/). Защищённые ссылки: [Microsoft Safe Links](https://learn.microsoft.com/en-us/defender-office-365/safe-links-about).
